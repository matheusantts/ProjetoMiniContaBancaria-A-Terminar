# 🏦 Mini Sistema Bancário

> Aplicação de terminal que simula operações financeiras básicas, desenvolvida em Java.

---

## 📋 Funcionalidades

- ✅ Criar conta bancária
- ✅ Realizar depósitos
- ✅ Realizar saques
- ✅ Consultar saldo

## 🚀 Como executar

**Pré-requisitos:** Java 11 ou superior instalado.

```bash
# Clone o repositório
git clone https://github.com/matheusantts/nome-do-repositorio.git

# Acesse a pasta do projeto
cd nome-do-repositorio

# Compile
javac Main.java

# Execute
java Main
```
